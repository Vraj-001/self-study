Built in Data types 
- in the programming, data type is an inportant concept.
- Variables can store data of different types, and different types can do different things.
- Pyhton has the following data types built-in by default, in these categories:

1. Text Type: str (stirng)
2. Numeric types: int(integer), float(float), complex(complex)
3. Sequence types: list, tuple, range
4. Mapping types: dict
5. set types: set, frozenset
6. Boolean Types: bool
7. Binary Types: bytes, bytearray, memoryview
8. None Type: NoneType
